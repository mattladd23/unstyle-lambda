# unstyle-lambda

A lightweight AWS Lambda function transpiled into JavaScript to serve static JSON data from an S3 bucket via API Gateway. A core component in hosting the Unstyle API.

## :key: Features

- :white_check_mark: Fetches JSON from a public S3 bucket
- :white_check_mark: Parses and returns the initialValues object
- :white_check_mark: CORS-enabled JSON response
- :white_check_mark: Minimal, serverless, and scalable

## :wrench: Tech Stack

- JavaScript (Typescript, ESM)
- AWS Lambda
- Amazon API Gateway
- AWS SDK
- Amazon S3
- Amazon Route 53
- AWS Certificate Manager
